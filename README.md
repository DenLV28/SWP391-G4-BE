Smart parking management system for managing vehicle entry, exit, parking slots, payments, and reservations.

# Project Objectives

The system helps manage parking buildings efficiently by:
- Monitoring parking slots in real time
- Managing vehicle check-in/check-out
- Improving parking security
- Reducing manual operations

---

# Main Features

## User Management
- Login / Logout
- Role Management
- User Profile

## Parking Management
- Real-time parking slot monitoring
- Vehicle entry/exit tracking
- Parking reservation

## Payment System
- Automatic fee calculation
- Online payment support
- Monthly subscription

## Security System
- Camera integration
- License plate recognition
- Vehicle history tracking
